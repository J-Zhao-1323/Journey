# Digital Media Portfolio Starter

A beginner-friendly static portfolio template for GitHub Pages, built with HTML, CSS and a small amount of JavaScript.

## What's included?

- `index.html`: the home page and section navigation
- `project-01.html`, `project-02.html`, `project-03.html`: example project case-study pages
- `style.css`: colours, typography, layout, responsive design and hover states
- `script.js`: mobile navigation menu and automatic footer year
- `assets/`: editable SVG placeholder covers; replace these with your own images whenever you're ready

## First edits to make

1. Search every HTML file for `Your Name` and `YN` and replace them with your name/initials.
2. Replace `your.email@example.com` with the email address you want to publish.
3. Replace the LinkedIn and GitHub links with your own public profile URLs.
4. Rewrite the sample project descriptions and case-study sections using only work you have permission to share.
5. Replace placeholder covers in `assets/` with your own images, and update the matching `src` paths in the HTML.

## Publish with GitHub Pages

1. Create a public repository named exactly `YOUR-USERNAME.github.io` (replace with your GitHub username).
2. Upload the files and folders from this template to the repository root. Keep `index.html` at the top level.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/(root)`, then save.
6. Wait for the workflow to finish and open `https://YOUR-USERNAME.github.io`.

GitHub Pages sites are publicly reachable. Do not publish passwords, private contact details, confidential client work or coursework you are not allowed to share.

## Image path example

If your image file is `assets/research-poster.jpg`, use:

```html
<img src="assets/research-poster.jpg" alt="A short description of the poster">
```

Use relative paths such as `assets/file.jpg` for images in this repository. File names are case-sensitive on the published site, so `Poster.jpg` and `poster.jpg` may be treated as different files.
